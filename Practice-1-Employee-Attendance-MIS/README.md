# Employee Attendance MIS Dashboard

## About the Project

This is my first Microsoft Excel MIS practice project created as part of my Data Analytics learning journey.

The project analyzes employee attendance data and presents key performance indicators, department-wise analysis, business insights, and recommended actions through an Excel MIS dashboard.

## Objectives

- Analyze employee attendance patterns
- Calculate key attendance KPIs
- Compare attendance performance across departments
- Identify departments or employees requiring attention
- Present findings in a clear and management-friendly dashboard

## Skills Practiced

- Microsoft Excel
- Data Cleaning & Validation
- Excel Formulas
- KPI Creation
- Pivot Tables
- Pivot Charts
- Dashboard Design
- Business Insights
- Recommended Actions

## Key KPIs

- Total Employees
- Total Working Days
- Total Present Days
- Total Leave Days
- Average Attendance %
- Total Late Days

## Dashboard Analysis

The dashboard includes:

- Department-wise Leave Days
- Department-wise Average Attendance %
- Key Business Insights
- Recommended Actions

## Tools Used

**Microsoft Excel**

## Learning Outcome

Through this practice project, I learned how to transform raw employee attendance data into a structured MIS report and dashboard, and how to interpret data to generate business insights and recommended actions.
